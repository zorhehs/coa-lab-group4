Reading the cache array

Hit — the block was already in the set. Miss — fetched from memory. COMP / CAPA / CONF is the 3C type; a red tag floating out of the cell is the evicted line. Victim hit — found in the victim cache and swapped back without a memory read. Left dot: valid bit. Right dot: dirty bit (write-back only). Bars under a line: LRU age, full = most recently used.

The 3C miss types

Compulsory — first touch of a block; no cache avoids it.
Capacity — a fully associative cache of the same size would also miss: the working set is too big.
Conflict — only the mapping caused it; more ways (or a victim cache) would have kept the block.

Workflow

1. Set geometry and policies in the sidebar; the whole trace re-runs instantly.
2. Pick a preset trace, generate a pattern, or paste a Dinero / Valgrind trace.
3. Step through the address decode and the array; the statistics and the access log follow the current step.
4. Open Experiments to sweep a parameter; hover a bar for its numbers; export CSV for the report.
