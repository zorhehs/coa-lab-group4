READING THE CACHE ARRAY

HIT — the block was already in the set MISS — fetched from memory; COMP / CAPA / CONF is the 3C type, a red tag floating out is the evicted line VICTIM — found in the victim cache and swapped back, no memory read left LED valid bit · right LED dirty bit (write-back only) bars under a line: LRU age, full = most recently used

THE 3C MISS TYPES

Compulsory — first touch of a block; no cache avoids it.
Capacity — a fully associative cache of the same size would also miss: the working set is too big.
Conflict — only the mapping caused it; more ways (or a victim cache) would have kept the block.

WORKFLOW

1 set geometry and policies in CONFIGURATION — the whole trace re-runs instantly.
2 load a preset, generate a pattern, or paste a Dinero / Valgrind trace.
3 step through ADDRESS DECODE and the array; COUNTERS and the ACCESS LOG follow the current step.
4 RUN SWEEP in EXPERIMENTS to compare settings — hover a bar for its numbers, EXPORT CSV for the report.
